# Artseek frontend

React SPA built with Vite and React Router framework mode.

## Requirements

- Node.js 22+
- pnpm 10+

## Run

```powershell
pnpm install
pnpm dev
```

Open the URL printed by the development server. During development, Vite proxies
`/api` requests to the backend target configured in `vite.config.js`.
